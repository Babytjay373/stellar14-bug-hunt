# Attendees wall

Everyone who came to the Stellar 14 build days Meetup on Saturday 10 October 2026 at Payaza Africa, Labone.

Add yourself with one new file (issue #17). One file per person means nobody's PR ever clashes with anyone else's.

1. Open this folder on GitHub and click **Add file**, then **Create new file**.
2. Name the file `your-github-username.md`.
3. Copy the template below, fill it in, and click **Propose changes**, then **Create pull request**.

```markdown
# Your Name

- City: Accra
- Today I was: Coder (Team Kente) / Content Crew (Hype Reporter)
- I came because: one sentence
- Find me: @your_x_handle
```

See `nyuiela.md` for an example.
